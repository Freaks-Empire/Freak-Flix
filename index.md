## What is Freak-Flix?

Freak-Flix transforms your video collection into a beautiful, Netflix-like interface. Built with Flutter, it works offline and supports multiple cloud storage backends without requiring a server.

### Perfect for:
- 🎬 **Movie collectors** who want automatic poster and metadata fetching
- 📺 **TV show enthusiasts** who need episode tracking and organization  
- 🍿 **Anime fans** with AniList integration for accurate metadata
- 🔒 **Privacy-conscious users** who prefer local/cloud storage
- ☁️ **Multi-device users** who want to stream from OneDrive, SFTP, FTP, or WebDAV

---

## ✨ Features

- **📚 Smart Library Organization**: Automatically categorizes Movies, TV Shows, Anime, and Adult content
- **🧠 Rich Metadata**: TMDB for movies/TV, AniList for anime, StashDB for adult content
- **☁️ Cloud Streaming**: Stream directly from OneDrive, SFTP, FTP, and WebDAV
- **🎬 Premium Player**: High-performance video playback with resume support
- **🔒 Privacy First**: Works offline, no server required, optional adult content segregation
- **📱 Cross-Platform**: Windows, Android, and Web

## 🚀 Quick Start

### Prerequisites
- [TMDB API Key](https://www.themoviedb.org/documentation/api) (free)

### Installation
1. Download for your platform from the [releases page](https://github.com/Freaks-Empire/Freak-Flix/releases)
2. Launch Freak-Flix
3. Enter your TMDB API key in Settings
4. Add your media folders and enjoy!
