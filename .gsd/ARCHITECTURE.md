## Overview

**Freak-Flix** is a local-only, Netflix-style media library application built with Flutter. It runs on **6 platforms**: Windows, macOS, Linux, Android, iOS, and Web (via Netlify). The app fetches rich metadata from external APIs and provides a cinematic browsing/playback experience.

## Data Flow

1. **Setup:** User completes setup wizard → `SettingsProvider.completeSetup()`
2. **Profile:** User selects profile → `ProfileProvider.selectProfile()` → loads per-user data
3. **Library Scan:** User adds folder → `LibraryProvider.pickAndScan()` / `rescanOneDriveFolder()` / `_scanRemoteFolder()`
4. **Metadata Enrichment:** `MetadataService` matches filenames via `TmdbService` → enriches `MediaItem` → `SidecarService` writes .nfo
5. **Browse:** Screens read from `LibraryProvider` filtered views + call discover services (TMDB/Trakt/AniList/StashDB)
6. **Playback:** User taps item → `VideoPlayerScreen` → `media_kit` (native) or WebView (web) → `PlaybackProvider` tracks progress → `ProfileProvider.updateProgress()`
7. **Sync/Backup:** `DataBackupService.exportState()` / `AutoBackupManager` (Windows-only)

## Conventions

**Naming:**
- Files: `snake_case.dart`
- Classes: `PascalCase`
- Providers: `{Domain}Provider extends ChangeNotifier`
- Services: `{Domain}Service` (singletons or injected via Provider)

**Structure:**
- Feature screens in `lib/screens/` with detail sub-screens in `details/`
- Reusable widgets in `lib/widgets/` with sub-groups (settings/, ads/, profile/, video_player/)
- Services in `lib/services/` (flat + monitoring subdir)
- Models in `lib/models/` (flat, no inheritance hierarchy)

**State Management:**
- `provider` package with `ChangeNotifierProvider` for mutable state
- `Provider.value` for service injection
- Profile ← Library sync via `addListener` callback

**Routing:**
- `go_router` with `StatefulShellRoute` for tab persistence
- Guards in `redirect` callback (setup, profile, adult content)

**Persistence:**
- Custom `PersistenceService` writing JSON files to app documents directory
- `flutter_secure_storage` for credentials
- `shared_preferences` for simple key-value (legacy, being migrated)

**Testing:**
- `flutter_test` framework
- Security tests in `test/security/`
- Unit tests in `test/unit/`
- Test helpers in `test/helpers/`
